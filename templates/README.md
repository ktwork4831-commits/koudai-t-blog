# 記事テンプレート

普段は「記事追加の依頼.txt」をコピーして、このチャットに貼り付けて使ってください。
タイトル・ジャンル・本文を埋め、画像があれば添付するだけで依頼できます。
本文の構成は自由です。見出しを使わない短い記事でも構いません。

「article.md」は直接Markdownを編集したい場合のひな形です。
このフォルダにある間は記事一覧に表示されません。

直接追加するときは、次の項目を変更してから src/posts/ にコピーします。

- ファイル名とslug：既存記事と重複しない半角英数字・ハイフン
- date：実際の投稿日（YYYY-MM-DD）
- title、category、description：記事に合わせて変更
- tags：不要なら項目ごと削除
- thumbnail：一覧用の画像。本文冒頭には自動表示されません
- 本文の画像：使う位置に配置。不要なら画像の行を削除
- 見出しと本文：不要な節は削除

画像は src/assets/images/posts/記事のslug/ に保存し、
Markdownには /assets/images/posts/記事のslug/画像名.webp と書きます。
サンプルのcover.webpと01.webpは実ファイルではないため、使用する画像に差し替えてください。
WebP化・圧縮・画像パス設定を任せたい場合は、依頼用テンプレートか記事作成ツールを使ってください。

保存後にプロジェクトのフォルダで node scripts/build.mjs を実行すると、
記事ページ・一覧・ジャンル・検索に反映されます。
